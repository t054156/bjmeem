Connect BJmeem to Supabase

The dashboard is installed but not linked to a database yet.

  1. Create a project at supabase.com.
  2. Run the migrations: supabase db push
  3. Copy Project URL and anon key from Project Settings → API.
  4. Paste them into js/config.js and redeploy.
  5. Make yourself owner in the SQL editor:
    update public.profiles set role='owner' where email='you@example.com';

Only the anon key goes in js/config.js. The service-role key must never leave Supabase.
